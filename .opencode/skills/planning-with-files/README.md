# planning-with-files

Skill para planear tasks y dejar que el noter before each action: `task_plan.md`.

## Qué hace

- Fuerza a usar markdown como memoria
- Crea fases con checkboxes
- Actualiza status después de cada fase
- Usa `notes.md` para guardar investigación
- El resultado final va a un deliverable

## Cuándo usarlo

- Tareas de largo periodo
- Investigaciones
- Crear o refactorizar algo de varias piezas
- Tareas que usan varios archivos

## Estructura mínima

```
project/
├── task_plan.md
├── notes.md
├── deliverable.md
└── ...doc
```

## Reglas clave

- Antes de cada fase: re-leer `task_plan.md`
- Después de cada fase: marcar checkboxes y actualizar Status
- No
- Documentar errores con fecha
- No abusar de subcutidos; guardarlos en `notes.md`, no en contexto
