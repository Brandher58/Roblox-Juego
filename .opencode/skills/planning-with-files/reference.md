# Reference: Manus-Style Planning

## Loop

```
Create task_plan.md → Research → Write notes.md → Create deliverable → Mark delivered
```

## File naming

| File | Name in repo |
|------|-------------|
| plan | `task_plan.md` |
| notes | `notes.md` |
| deliverable | deliverable

## Status

Use this three-line structure in task_plan.md:

```markdown
## Status
**Currently in Phase X** - <one sentence>
```

## Errors

Keep an explicit `## Errors` section that grows with each attempt:

```markdown
## Errors
- [YYYY-MM-DD] Fired "hit" remote instead of "hitDamage" on enemy death
```
